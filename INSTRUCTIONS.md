## Структура файлов

```
src/
├── components/        # UI компоненты
├── views/            # View классы
├── models/           # Модели данных
├── presenters/       # Presenter классы (бизнес-логика)
├── api/              # Mock API
├── data/             # Моковые данные
├── utils/            # Утилиты (роутер, форматтеры)
└── app.js            # Главный файл

index.html            # Главная страница
```

## Как запустить

1. Откройте `index.html` в браузере
2. Или используйте локальный сервер (обязательно для ES6 модулей):

   ```bash
   # Python 3
   python -m http.server 8000

   # Node.js
   npx http-server
   ```

3. Откройте в браузере: `http://localhost:8000`

## Навигация

- `#overview` - Обзор
- `#transactions` - Транзакции
- `#budgets` - Бюджеты
- `#analytics` - Аналитика
- `#reports` - Отчеты

## Архитектура MVP

- **Model** - содержит структуру данных и методы работы с ними
- **View** - отвечает только за отображение UI
- **Presenter** - содержит бизнес-логику, связывает View и Model

## Подключение к MockAPI.io

Для лабораторной работы 8 необходимо подключить реальный Mock API:

1. Создайте проект на https://mockapi.io/projects
2. Создайте ресурсы (transactions, budgets, categories и т.д.)
3. Обновите `src/config/apiConfig.js` с URL вашего проекта
4. Установите `USE_MOCK_API = false` для использования реального API

Подробная инструкция в файле `MOCKAPI_SETUP.md`
