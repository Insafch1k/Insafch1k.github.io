# Добавление транзакций через MockAPI.io

## Изменения в MockAPI.io

**Никаких изменений в структуре ресурсов НЕ требуется!**

Функция добавления транзакций использует существующий ресурс `transactions` и метод `POST` для создания новых записей.

## Формат данных транзакции

При создании новой транзакции отправляются следующие данные:

```json
{
  "date": "2024-01-15",
  "description": "Покупки в магазине",
  "category": "food",
  "categoryName": "Продукты",
  "amount": -50.0,
  "type": "expense"
}
```

### Поля транзакции:

- **`date`** (String) - Дата транзакции в формате `YYYY-MM-DD`
- **`description`** (String) - Описание транзакции
- **`category`** (String) - ID категории (например: `food`, `transport`, `entertainment`, `home`, `health`, `bills`, `shopping`, `salary`)
- **`categoryName`** (String) - Название категории на русском языке
- **`amount`** (Number) - Сумма транзакции:
  - Отрицательное значение для расходов (`expense`)
  - Положительное значение для доходов (`income`)
- **`type`** (String) - Тип транзакции: `expense` или `income`

## API Endpoint

**POST** `https://693335a5e5a9e342d2723bf8.mockapi.io/transactions`

### Пример запроса:

```javascript
POST https://693335a5e5a9e342d2723bf8.mockapi.io/transactions
Content-Type: application/json

{
  "date": "2024-01-20",
  "description": "Обед в ресторане",
  "category": "food",
  "categoryName": "Продукты",
  "amount": -150.00,
  "type": "expense"
}
```

### Пример ответа:

```json
{
  "id": "123",
  "date": "2024-01-20",
  "description": "Обед в ресторане",
  "category": "food",
  "categoryName": "Продукты",
  "amount": -150.0,
  "type": "expense",
  "createdAt": "2024-01-20T10:30:00.000Z"
}
```

## Автоматическое поведение MockAPI.io

MockAPI.io автоматически:

- Генерирует уникальный `id` для новой транзакции
- Добавляет поле `createdAt` с временем создания
- Сохраняет транзакцию в ресурсе `transactions`

## Проверка работы

После создания транзакции через форму в приложении:

1. Проверьте список транзакций в приложении - новая транзакция должна появиться
2. Проверьте в MockAPI.io - новая запись должна появиться в ресурсе `transactions`
3. Проверьте endpoint: `GET https://693335a5e5a9e342d2723bf8.mockapi.io/transactions`

## Важные замечания

1. **Валидация**: MockAPI.io автоматически валидирует типы данных. Убедитесь, что:

   - `date` - строка в формате даты
   - `amount` - число (может быть отрицательным)
   - `type` - строка `expense` или `income`

2. **Категории**: Убедитесь, что `category` соответствует одной из существующих категорий в приложении:

   - Для расходов: `food`, `transport`, `entertainment`, `home`, `health`, `bills`, `shopping`
   - Для доходов: `salary` (и другие, если добавлены)

3. **Синхронизация**: После создания транзакции приложение автоматически обновляет список транзакций, загружая данные заново с сервера.
